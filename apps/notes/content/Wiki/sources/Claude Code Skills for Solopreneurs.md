# Claude Code Skills for Solopreneurs

## Takeaways
- **opc.dev** bundles nine free open-source skills: SEO/GEO, RequestHunt demand research, domain hunter, NanoBanana image gen, Twitter/Reddit analysis, etc.
- Install via `npx skills add ReScienceLab/opc-skills --skill …`; optional API keys (DataForSEO, TwitterAPI, Gemini, RequestHunt).
- SEO-GEO skill targets AI search visibility (ChatGPT, Perplexity) plus traditional SEO—schema, keywords, SERP scripts.
- RequestHunt scrapes feature requests/complaints across Reddit, X, GitHub, YouTube, LinkedIn for demand validation.
- Skills are CLI-script wrappers with documented example commands—pattern mirrors vault `.agents/skills` but market-focused.

Candidate skill imports for solopreneur/brand lane in vault; compare structure to local skill conventions before adopting.
