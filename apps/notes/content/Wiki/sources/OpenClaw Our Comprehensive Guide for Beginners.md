# OpenClaw: Our Comprehensive Guide for Beginners

## Takeaways

- **Every.to "Claw School"** onboarding for **OpenClaw** — Peter Steinberger's open-source personal AI assistant framework.
- **Lives in messaging apps** (WhatsApp, Telegram, Discord, SMS): casual, always-on, no separate app; personality + memory that evolves.
- **Self-extending:** when it lacks an integration, it writes the code to add it (email, calendar, phone via Twilio, smart home, etc.).
- **Proactive by design:** can monitor calendar/inbox and act in the background per rules you set — unlike reactive chatbots.
- **Defaults are minimal access:** only knows what you tell it until you explicitly connect tools; confidently wrong on facts — verify high-stakes output.
- **Use cases in guide:** morning briefings, inbox triage, research, content drafts, booking, project tracking — framed for non-technical users.

## Notes

Written by Every (Willie Williams, Dan Shipper). Positions OpenClaw as a *personal* assistant with boundaries you control, not an omniscient oracle. Good entry point before Johann's security guide or Steinberger's inference-speed workflow posts.
