# The next chapter EpicAI.pro

## Takeaways
- Kent C. Dodds announces **EpicAI.pro**—next education platform after Testing JavaScript, Epic React, and Epic Web—focused on AI-native application architecture, not vendor hype.
- Thesis: UI paradigm shifts from forms/buttons to **conversational agents** orchestrating multi-service workflows; developers must build **machine-consumable interfaces**.
- Four curriculum pillars: designing for AI interaction, structuring data/capabilities, **Model Context Protocol (MCP)**, and security/reliability (auth, tool poisoning, etc.).
- Launch path: free live event live-coding an MCP server; EpicAI.pro under construction with enduring-principles framing (skeptical of blockchain/NFT-style hype cycles).
- Positions MCP as the standard for agents to discover and use app capabilities securely.

## Notes
Strong alignment with vault agentic lane and existing MCP/Raindrop/QMD tooling. Complements Simon Willison's Agentic Engineering Patterns and Kent's prior testing/React teaching style.
