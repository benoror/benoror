# Twitch live coding LowCode streaming

## Takeaways
- Jordan Lewis's 6-month retrospective on **LARGE DATA BANK** Twitch live-coding channel—setup guide for coding streams as education + entertainment.
- **OBS** is the core tool: scenes for desktop capture, face cam, audio; start bare-bones (desktop + webcam + mic) before investing in gear.
- Desktop scene best practice: external monitor full capture, large editor font (~26pt), strip distracting UI chrome so viewers can follow code.
- Advanced setup: keyboard cam, StreamLabels, Streamlabs alerts, whiteboard/iPad scene, global hotkeys for scene switching; most time on one "workhorse" scene.
- Platform note: Twitch culture vs YouTube Live for professional content; OBS config largely portable.
